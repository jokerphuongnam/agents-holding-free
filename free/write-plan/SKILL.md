# write-plan

Write one markdown file the engineer can build from.

1. The outcome the user can see when it is done.
2. In scope: the few behaviors that outcome needs.
3. Out of scope: what this plan leaves for later.
4. Done when: three checks a person can run.

Hand the file to the engineer. One plan is enough for this company.
