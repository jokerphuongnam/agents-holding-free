# agents-holding free

A small company folder you can set up and use. It is not the full company OS.

This edition gives you:

- one company directory
- two staff files, `ceo` and `engineer`
- one place to write a plan, `cache/plans/`
- one short skill for writing that plan

It does not include the holding tree, child companies, the product and QC roster, skill library, plan history, hop, or the Mac app. Those stay in the private edition.

## Setup

```bash
git clone https://github.com/jokerphuongnam/agents-holding-free.git
cd agents-holding-free
./setup.sh my-product
```

That writes `./.agents/my-product-company/`. Point your agent at `system/staffs/leadership/ceo.md` and work in that folder.

The free company has no installer for Claude, Cursor, or Codex, and no mission-control app. You open the files yourself.
